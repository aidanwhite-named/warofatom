# War of Atom — 프로토타입 규칙 v0.6

> 프로토타입 단계. 모든 수치는 `src/engine/config.ts`에 있고, 시뮬레이터(`npm run sim`, `npm run tune`) 결과를 보고 계속 바꾼다.

## 1. 승리 조건 — 엔트로피
- 각 플레이어의 **엔트로피는 0에서 시작**해 차오른다. **40에 도달하면 소멸(패배)**.
- 엔트로피가 오르는 경우
  - **자연 증가**: 내 턴이 시작될 때마다 +1
  - **피격**: 상대 유닛이 공격했는데 그 레인을 막을 내 유닛이 없으면 공격력만큼 +
  - **카드 효과**: 일부 카드는 상대 엔트로피를 직접 올린다
  - **덱 고갈**: 덱이 비었는데 드로우해야 하면 +2
  - **방치**: 낼 수 있는(교단은 붕괴할 수 있는) 손패가 있는데 한 장도 사용하지 않고 턴을 끝내면 +1

## 2. 전장 (레인형)
- 양측에 **레인 4개**, 레인마다 내 칸 1개 + 상대 칸 1개가 마주 본다.
- 유닛은 비어 있는 내 칸에만 소환한다.

### 2-1. 원소 타일 (주기율 전장 1단계)
- 매 판 시작 시 원소 풀 24종(`src/data/elements.ts`, 종족 12개 × 2종)을 섞어 **레인마다 가운데에 원소 1개**를 놓는다. 나머지는 보충용 더미.
- **장악**: 내 턴이 시작될 때 어떤 레인에 내 유닛만 있고 상대 유닛이 없으면 그 레인 장악 게이지 +1, 아니면 0으로 초기화. **2**가 되면 그 원소를 획득하고, 그 자리에 더미에서 새 원소가 놓인다.
  - 결속의 방벽은 **격자로 붙잡는다**: 맞은편에 적이 있어도 내 유닛이 버티고 있으면 게이지가 오른다.
- **원소 공명** (가진 원소에 적용)
  - 같은 원소 기호의 카드: 비용 −1 (최소 1)
  - 같은 계열(원소 group = 카드 종족)의 유닛: 소환 시 +1/+1

### 2-2. 진영별 원소 사용 (주기율 전장 2단계)
같은 원소라도 진영마다 쓰는 법이 다르다.
- **반응성 연맹 — 반응** (행동): 가진 원소 2개 + 금화 3을 소모해 고른 레인의 적에게 3 피해(저항 적용), 상대 엔트로피 +1. 금속 + 비금속이면 **이온 반응**으로 피해 +1. 비활성 원소(Ne, Ar, Og, Rn)는 반응하지 않는다. 소모한 원소의 공명은 잃는다.
- **결속의 방벽 — 결합** (자동): 원소를 획득할 때 1장 드로우. 가진 원소 1개당 턴 시작 결합력 +1 (격자처럼).
- **붕괴의 교단 — 붕괴**
  - 붕괴 사슬 (자동): 가진 방사성 원소가 내 턴 시작마다 한 단계씩 붕괴하고(U → Th → Ra → Rn → Pb, Og → Lv → Fl → Cn → Pb), 그때마다 상대 엔트로피 +1. 바뀐 원소에 따라 공명 계열도 바뀐다.
  - 원소 붕괴 (행동): 가진 원소 1개를 소모해 붕괴열 +2.

### 2-3. 지맥 (주기율 전장 3단계)
- 매 판 시작 시 처음 깔린 원소 4개 중 하나의 계열이 **지맥**이 된다 (판에 지맥 원소가 항상 하나 이상 있다).
- 지맥 계열 원소의 공명은 **2배**: 같은 원소 카드 비용 −2 (최소 1), 같은 계열 유닛 소환 시 +2/+2.
- 진영마다 종족이 4개씩이라 지맥이 각 진영에 유리하게 걸릴 확률은 같다. 평균 상성은 그대로 두고 판마다 유불리를 만든다.

### 2-4. 주기 테크트리 (주기율 전장 4단계)
- **연구 단계** = 지금까지 획득한 원소의 최고 **주기** (실제 주기율표 기준: Li·C·N·O·F 2주기 … Fe·Cu·Ca 4주기, Sn 5주기, Ce·Nd 6주기, U·Th·Fl·Og 7주기). 원소를 반응·붕괴로 써도 내려가지 않는다.
- 낼 수 있는 카드 레벨 상한 = max(진영 기본 상한, 연구 단계 + 2)
  - 연맹·방벽: 기본 5 → 4주기 원소로 레벨 6, 5주기로 7, 6주기로 8, 7주기로 9가 열린다. 후반 카드를 쓰려면 고주기 원소 타일을 차지해야 한다.
  - 교단: 기본 9 (제한 없음). 방사성 붕괴로 무거운 원소를 직접 만들어 내는 진영이라는 설정. 교단도 막으면 잠긴 고레벨 손패가 붕괴 연료로 바뀌어 상성이 크게 흔들린다 (8절).

- 수치는 `config.ts`의 `elements`. 측정은 `npm run elements` (원소 끔 / 3단계까지 / 4단계까지 상성 비교, 진영별 획득·사용 횟수·연구 단계, 원소별·지맥별 영향).

## 3. 카드
- **손패 상한 6장**. 손패가 가득 차 있으면 드로우하지 않는다 (카드는 덱에 남는다).
- **사용한 만큼 드로우**: 내 턴 시작에 지난 턴 손패에서 사용한 장수만큼 뽑는다 (첫 턴은 1장). 사용 = 손패에서 낸 유닛·아이템·마법 + 교단 손패 붕괴 (턴당 1장까지만 센다 — 다 세면 붕괴할수록 드로우가 늘어 v0.3의 무제한 순환이 돌아온다).
- **레벨 = 비용 등급** (1~9). 레벨 N 유닛은 자원 N을 소모한다.
- **유지비(upkeep)**: 카드에 따라 0~3. 내 턴 시작마다 자원에서 지불하고(레인 순서), 못 내면 그 유닛은 파괴된다. 유지비가 있는 카드는 같은 레벨에서 더 강하게 만들 수 있다 (`src/balance/weights.ts`의 `upkeepRebate`). 현재 모든 카드는 유지비 0.
- **방어력 N** (`armor:N`): 받는 전투 피해를 N 줄인다. **저항 N** (`resist:N`): 받는 능력·마법 피해(맞은편 피해 등)를 N 줄인다. 둘 다 최소 0이며, 일부 카드에만 붙는 키워드다.
- **기력 N** (`charge:N`): 내 턴 시작마다, 그리고 전투에서 살아남을 때마다 기력 +1. N이 차면 "충전 시"(`onCharge`) 효과가 발동하고 0으로 돌아간다 (반복 발동). 회복은 별도 스탯 없이 "충전 시: 체력 N 회복"(`healSelf`, 상한은 카드 체력 + 장착 아이템 체력)으로 표현한다.
- 아이템의 방어력·저항 키워드는 장착한 유닛에 더해진다.
- 기본 카드 풀: 진영마다 29종(덱 24장의 120%). 덱 프리셋(`decks.ts`)은 그중 일부만 쓴다.
- 카드 밸런스 도구: `npm run card -- audit`(전체 점수 점검), `npm run card -- make --level 4 --upkeep 1 --fx entropy:2+chain`(남은 예산으로 가능한 공격/체력 조합 제안). 레벨별 예산·가중치는 `src/balance/weights.ts`.
- 모든 카드는 원소(element), 진영(faction), 종족(race)을 가진다. 진영 3개 × 종족 4개 (7절).
- **카드 종류**: 유닛 / 아이템 / 마법. 진영마다 낼 수 있는 종류가 정해져 있고 다른 진영은 쓸 수 없다 (`src/engine/game.ts`의 `FACTION_KINDS`).

| 진영 | 고유 행동 | 형태 |
|---|---|---|
| 반응성 연맹 | 마법 | 덱 카드. 금화로 내고, 고른 레인에서 효과만 발동하고 버려진다. **과부하**: 내 엔트로피 +6 대신 비용 -1 (선택) |
| 결속의 방벽 | 장착 | 덱 카드. 내 유닛 칸에 내면 그 유닛에 공격/체력을 더한다. 유닛이 죽으면 장비도 사라진다 |
| 붕괴의 교단 | 계승 | 카드 없음. 보드 붕괴 때 다른 내 유닛을 지정하면, 붕괴한 유닛의 소환 시 효과가 그 자리에서 다시 발동하고 파괴 시 효과는 물려받는다 |

## 4. 턴 진행
1. **시작 단계**: 엔트로피 +1 → 진영 규칙에 따라 자원 갱신 → 지난 턴 사용한 장수만큼 드로우 (선공 첫 턴은 드로우 없음) → 반감기 카운트 감소·유지비·기력 → (교단) 붕괴 사슬 → 원소 장악 판정
2. **메인 단계**: 아래 행동을 원하는 순서·횟수로
   - 유닛 소환
   - (연맹) 마법 / (방벽) 아이템 장착
   - (방벽) 격자 배치
   - (교단) 원소 붕괴 (손패·유닛·가진 원소)
   - (연맹) 원소 반응
   - 공격: 이번 턴에 소환되지 않았고 아직 공격하지 않은 내 유닛이 같은 레인을 공격
     - 상대 유닛이 있으면 **공격자가 먼저** 공격력만큼 피해. 대상이 쓰러지면 반격 없음, **버텨내면 반격**(대상 공격력만큼). 방어력은 공격·반격 모두에 적용
     - 비어 있으면 상대 **엔트로피 + 공격력**
3. **종료**: 턴 종료 선언 (방치 페널티 판정) → 상대 턴

- 시작 손패와 후공 첫 턴 자원 보너스는 진영별 (선공 이점 보정, 같은 보정이 진영마다 가치가 달라서)

| 진영 | 선공 손패 | 후공 손패 | 후공 첫 턴 자원 |
|---|---|---|---|
| 연맹 | 2 | 6 | +1 |
| 방벽 | 4 | 6 | +1 |
| 교단 | 5 | 5 | +0 |

## 5. 진영별 자원

### 반응성 연맹 (Reactive Union) — 금화
- 턴 시작 시 수입 `2 + floor(내 턴 수 / 3)` (최대 5) **+ 이자** `floor(보유 금화 / 4)` (최대 2)
- 금화는 **다음 턴으로 이월**된다. 보유 상한 10.
- 키워드 `연쇄`: 이번 턴에 이미 연맹 유닛을 소환했다면 추가 효과 발동

### 결속의 방벽 (Covalent Matrix) — 결합력
- **격자 더미**(덱과 별도, 11장)에서 **턴당 1개**를 전장에 배치할 수 있다. 덱에 대지 카드가 섞이지 않으므로 손패 사고가 없다.
- 턴 시작 시 결합력 = 격자 수 (사용하지 않은 결합력은 사라짐). 격자 0개로 시작 → 첫 턴은 자원 0
- **격자 공명**: 격자 8개 이상이면 턴 시작 시 결합력 +2

### 붕괴의 교단 (Cult of Decay) — 붕괴열
- 턴 시작 시 붕괴열 = `1 + floor(내 턴 수 / 3)` (사용하지 않은 붕괴열은 사라짐)
- **원소 붕괴**: 언제든지. 드로우는 없다 (v0.3에서 제거, 8절)
  - 손패 1장 파기 → 붕괴열 +(그 카드 레벨)
  - 내 유닛 1기 파기 → 붕괴열 +(그 유닛 레벨). 이때 계승 가능 (3절)
- 키워드 `반감기 N`: 소환 후 내 턴이 N번 시작되면 붕괴(파기)

## 8. 밸런스 기록
v0.2 (단순 봇, 진영 조합당 500판, 행 기준 승률)

| | vs 연맹 | vs 방벽 | vs 교단 |
|---|---|---|---|
| 연맹 | 50% | 42% | 61% |
| 방벽 | 52% | 53% | 34% |
| 교단 | 32% | 65% | 49% |

- 상성 구조: 방벽 > 연맹 > 교단 > 방벽 (가위바위보형, 모두 35~65% 이내)
- 최대 엔트로피를 35~40으로 늘리면 방벽이 크게 유리해짐 (후반 진영) → 30 유지

v0.3 (봇이 반감기로 사라질 유닛을 보드 붕괴하도록 보완, 500판)

| | vs 연맹 | vs 방벽 | vs 교단 |
|---|---|---|---|
| 연맹 | 50% | 42% | 64% |
| 방벽 | 52% | 53% | 42% |
| 교단 | 32% | 55% | 48% |

- 봇 보완 직후(v0.2 수치 그대로) 교단이 92~93%. 원인은 붕괴할 때마다 1장 드로우 → 무제한 순환. 보드 붕괴 보너스(+2)는 거의 무관
- 붕괴 드로우 1 → 0, 붕괴열 증가 2턴 → 3턴마다로 조정
- 덱 48장, 최대 엔트로피 40~60, 14개 수치 동시 탐색 모두 시도했지만 진영 수치만으로는 ±15 안쪽으로 안 들어옴 (상성 순환)
- 교단이 낀 대전은 선공승 12~26% → 후공 보정(손패 6장, 자원 +1)이 교단의 붕괴 연료로 과하게 작동
- 반감기 할인(`src/balance/weights.ts`)은 `npm run calibrate`로 확인한 결과 현재 값 유지

v0.4 (진영 고유 행동 추가 + 진영별 선후공 보정, 500판)

| | vs 연맹 | vs 방벽 | vs 교단 |
|---|---|---|---|
| 연맹 | 46% | 48% | 62% |
| 방벽 | 52% | 49% | 46% |
| 교단 | 37% | 54% | 52% |

- 대전별 선공승 39~60% (v0.3은 교단이 낀 대전 12~26%)
- 추가 카드: 연맹 마법 3장(연소·중화·테르밋 반응), 방벽 아이템 3장(나노튜브 장갑·질화붕소 칼날·텅스텐카바이드 도금). 예산보다 1점 약하게 시작
- 선공×후공 9개 순서쌍의 선공 승률을 전부 50%에 맞추는 탐색으로 손패·후공 자원·과부하 엔트로피(2→6)·격자 더미(9→11) 조정
- 첫 탐색은 연맹 손패를 2/3장까지 깎았다 → 원인인 마법을 약하게(연소 피해 3→2, 중화 엔트로피 3→2) 하고 연맹 손패를 3/6으로 되돌림
- 남은 문제: 연맹 > 교단 62%. 방벽 선공 vs 연맹 후공, 방벽 미러의 선후공 차이 (다른 시드 검증 67% / 37%)
- `npm run calibrate`: 아이템은 점수표와 일치. 계승 때문에 소환 효과가 있는 반감기 카드(플루토늄 사신, 우라늄 노심)가 점수표보다 크게 강함 → 점수표에 계승 항목 필요

- 진영 전체 승률 연맹 51% / 방벽 49% / 교단 50%. 판당 획득 방벽 4.0 / 연맹 2.3 / 교단 1.6개
- 연맹 반응을 처음에 금화 비용 없이(피해 4+2, 엔트로피 2) 넣었더니 연맹 vs 방벽 72%. 방벽 초반 방어 유닛을 공짜로 지워 9턴 러시 → 금화 3 비용, 피해 3+1, 엔트로피 1
- 방벽은 원소 보상(장악 1턴, 획득 드로우)을 키워도 결과가 같았다: 레인을 혼자 지키는 일이 드물어 받을 기회가 없음 → "버텨서 장악"(맞은편에 적이 있어도 게이지 진행)으로 해결
- 지맥에 "장악 1턴 단축"도 넣었다가 방벽이 원소를 너무 쉽게 모아(연맹 vs 방벽 49→42%) 공명 2배만 남김
- 테크트리를 세 진영 모두에 걸면 연맹 vs 교단 82%. 교단은 고레벨 카드를 붕괴로 일찍 내는 진영인데 원소를 가장 적게 얻는다. 비용 가산형(소프트 잠금)도 81~90%로 같았고, 교단 기본 상한 7은 잠긴 오가네손 거신이 붕괴 연료(+9)가 되어 방벽 vs 교단 31% → 교단 기본 상한 9(제한 없음)
- 남은 문제: 알칼리토 지맥에서 방벽 -26%p (36판, 연맹 Mg·Ca 카드가 비용 -2를 받는 영향으로 보임)

v0.6 (손패 상한 6·사용한 만큼 드로우·방치 페널티, 선타+반격 전투, 300판)

|---|---|---|---|

- 대전별 선공승 47~62%, 평균 15~30턴 (방벽 미러가 가장 길다)
- 규칙만 바꾸고 수치 그대로(최대 30)면 판이 18 → 13턴으로 짧아지고 방벽이 26~34%. 방벽은 첫 두 턴 결합력이 0이라 카드를 못 써 드로우도 못 받는다 → 방치 페널티는 낼 수 있는 카드가 있을 때만
- 최대 엔트로피 30 → 40: 후반 진영인 방벽이 살아남 (연맹 vs 방벽 65 → 52%)
- 교단 손패 붕괴를 '사용'으로 다 세면 교단 64%, 하나도 안 세면 40%. 턴당 1장까지만 세고 보드 붕괴 보너스 +2 → 0
- 선타 전투는 선공에 유리 (연맹 미러 선공승 31 → 68%) → 연맹 선공 손패 3 → 2
